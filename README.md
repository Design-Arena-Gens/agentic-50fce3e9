## Agentic Hello

A tiny, opinionated greeting canvas that turns “hi” into a friendly moment. Built with the Next.js App Router, Tailwind, and the Geist font family.

### What’s inside
- Personalized greeting that adapts to the current time of day
- Compliment cycler to keep the momentum upbeat
- Curated conversation starters so you never run out of small talk

### Local development
Install dependencies if you haven’t already, then start the dev server:

```bash
npm install
npm run dev
```

The app boots on [http://localhost:3000](http://localhost:3000).

### Production build

```bash
npm run build
npm run start
```

### Deployment
Ready for Vercel. Use the provided production command:

```bash
vercel deploy --prod --yes --token $VERCEL_TOKEN --name agentic-50fce3e9
```
